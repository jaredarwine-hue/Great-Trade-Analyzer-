# Great Trade Analyzer

A local, historical backtesting sandbox for trading-strategy research. It bundles the
**AI Trading Floor** skill — a self-contained Python toolkit (fetch data → backtest →
chart → interactive dashboard) plus an optional team of specialist AI agents for deeper
research.

Everything runs locally against historical data. **No live trading, no broker
connection, no real money.** Backtest results are not predictions.

## Layout

```
.claude/skills/ai-trading-floor/   the skill (docs, agents, scripts)
  SKILL.md                         entry point + agent-floor overview
  tutorial.md                      first-time, step-by-step setup walkthrough
  CONVENTIONS.md                   backtest-honesty + anti-overfitting rules
  CHART_RENDERER.md                chart rendering reference
  agent-*.md                       the specialist agent definitions
  requirements.txt                 Python dependencies
  scripts/                         the toolkit (see scripts/README.md)
  scripts/strategies/              built-in strategy definitions
  templates/CLAUDE.md              source of this repo's ./CLAUDE.md
CLAUDE.md                          project guide, always loaded by Claude Code
```

Outputs are written **CWD-relative** into `./data`, `./results`, and `./reports`. Those
folders are gitignored — they're regenerated by re-running the scripts.

## Getting started

In Claude Code, from this directory:

```
/ai-trading-floor tutorial
```

That walks through the setup one step at a time. To do it by hand instead:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r .claude/skills/ai-trading-floor/requirements.txt
python .claude/skills/ai-trading-floor/scripts/run_pipeline.py --ticker SPY --strategy sma_crossover
```

Then open `./reports/dashboard.html` in a browser — that's the headline output.

## Working on strategies

Add a new strategy through the `STRATEGIES` registry in `scripts/backtest.py` (see the
"HOW TO ADD YOUR OWN STRATEGY" block at the top of that file) rather than building a
separate engine — `backtest.py` is where look-ahead is prevented centrally.

Before trusting a number, read `CONVENTIONS.md` — especially §8 on avoiding overfitting.
Lead with out-of-sample results; a single in-sample window is not "the result."
